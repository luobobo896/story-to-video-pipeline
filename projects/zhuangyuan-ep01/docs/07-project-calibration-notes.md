## 三、案例记录

### 案例 1 · SH003：匀速漂移（命中 ME-001 / ME-009）

| 项 | 内容 |
|---|---|
| 镜头 | `EP01-SC01-SH003` 撑地抬头，4.096s，face_scale 35% |
| 测量 | 按 0.7s 间隔采样面部区域差异：**8.95 / 11.54 / 11.56 / 9.02 / 8.75** |
| 指标 | **CV = 0.13，R = 1.16**（自然表演应有 CV > 0.5、R > 3） |
| 现象 | 整段只有一个"瞪眼微张口"模板，只有头部角度在变 |
| 根因 | 单镜 4 秒只放了 1 个情绪节拍（`micro_beats=1`），模型没有节拍可演，只能把"抬头"这个动作摊匀到整段 |
| 处置 | `status=regen`。重做规格：0–1.2s 昏迷转苏醒（眼睑缓慢睁开、头抬起）→ 1.2–4.0s 聚焦"买状元"这件事（瞳孔收紧、眉心下压、呼吸变浅）。**首帧必须画半闭眼，不能画成瞪眼** |

### 案例 2 · SH001：掉落轨迹不符合重力（命中 PH-004）

| 项 | 内容 |
|---|---|
| 镜头 | `EP01-SC01-SH001` 被踹飞，5.088s |
| 测量 | 12fps 抽帧，帧间差分取运动质心行号 |
| 数据 | 0.0s→69.7；1.0s→69.3；**1.75s→83.5（最快段 +14.2）**；2.75s→90.0（+6.5）；**3.5s→92.9（+2.9，几乎停滞）**；5.0s→113.4（滑行/镜头后拉） |
| 结论 | 垂直位移速率**没有随时间递增**。1.75–3.5s 段几乎停滞，而自由落体在该区间应加速 |
| 附加事实 | 全程**未与木柱接触**（`qa_physics=fail`）——关键帧里柱子就在画面左侧，成片里人落在柱子前方地面 |
| 根因 | 生成模型无物理求解器，"撞柱"这个事件无法被保证；提示词只写了结果（"撞柱即停"），没写时序（何时、接触点、撞击后反应） |
| 处置 | `status=regen`，改用 `rules/PH-004` 的时序化写法 |

> 测量局限：质心含镜头后拉分量，只能作粗判，不是精确轨迹。

### 案例 4 · SH001：即梦 Dreamina 与 Higgsfield 的同镜成本/精度对照（2026-09-16）

同一条镜头、同一组输入（关键帧 `SH001` + `CH-001` + `EN-001` + `ST-001` + 同一提示词），两家跑出来的账单：

| 路线 | 模型 / 规格 | 积分 | 产物 |
|---|---|---|---|
| Higgsfield（本项目基线） | `seedance_2_0_mini` 720p 5s 24fps | **12.5** | `project/work/clips/EP01-SC01-SH001_v001.mp4` |
| 即梦 | `seedance2.0mini` 720p 5s | 30 | `clips/a5afbd37-….mp4` |
| 即梦 | `seedance2.0_vip` 1080p 5s 60fps | **165** | `jimeng_test/9cb5f62c-….mp4` |
| 即梦 | `seedance2.5` 1080p 5s 24fps | 320 | `clips/f5df88b5-….mp4` |
| 即梦 | `seedance2.0fast` 720p 5s | 25 | `34226c89-…` **队列 541,198 位，14:38 提交至今未出** |

> Higgsfield 的 `seedance_2_5` 1080p 6s（54 积分）来自 [docs/10](../../../docs/10-account-plans-and-credits.md) 的积分单价表（`generate cost` 实测），本项目未实测该规格。两家的"积分"是各自套餐的计价单位，跨平台只比量级、不比绝对金额。

复现命令（即梦这一次，积分 1801 → 1636）：

```bash
dreamina multimodal2video \
  --image project/work/keyframes/EP01-SC01-SH001_v001.png \
  --image project/work/assets/CH-001_v001.png \
  --image project/work/assets/EN-001_v001.png \
  --image project/work/assets/ST-001_v001.png \
  --prompt '@图片1为首帧。参考@图片2的人物形象、@图片3的场景布局、@图片4的画风色调。…' \
  --model_version seedance2.0_vip --video_resolution 1080p --duration 5
```

视觉十项对照（用 `tools/eye.py` 抽帧判读）：

| 视觉项 | 即梦 `2.0_vip` 1080p | 即梦 `2.5` 1080p |
|---|---|---|
| 首帧还原 | 与关键帧几乎 1:1 | 略偏 |
| 身份 / 服装 | 月白锦袍、深色腰束、发髻保持 | 同 |
| 场景 / 道具 | 后段太师椅数量翻倍、多出第二条红毯 | 同样增殖 |
| 运镜 | 拉过头：末帧人物只占画面高约 2%，远低于 ME-006 的 10% 下限 | 拉幅较小，人物仍可读 |
| 物理 | 从柱旁掠过，没有明确撞停感；未见穿柱 | 有明确撞停 |
| 水印 | 左上角常驻「AI生成」 | 同 |

结论：

1. **即梦出片一律带「AI生成」水印**，CLI 无关闭参数 → 直接进交付不可行，须裁边或改用 Higgsfield。
2. **同档位即梦更贵**：2.0mini 720p 即梦 30 积分 vs Higgsfield 12.5；1080p 多参考路线即梦 165（`2.0_vip`）/ 320（`2.5`）一条，Higgsfield `2.5` 1080p 6s 为 54。
3. **即梦 `2.0fast` 便宜但排不上队**（54 万位），不能作为常规路线。
4. 平台切换会把资产与一致性链搬到另一套账号体系，本片暂不改路线。

### 案例 5 · SH001「踢飞」的受力链与表情：规则本来就有，但没有一条进提示词（命中 PH-011 / ME-010 / ME-006 / ME-009）

作者看片后的判断——"动作没有合理的速度、力度与惯性反馈，人物表情与情境不符"——逐条对得上实测：

| 观察 | 证据 | 命中规则 |
|---|---|---|
| 腾空段近乎匀速，没有受力方向 | `prompt_zh` 全文只有"被一脚踹飞横穿厅堂砸向深色木柱"，没有受力点、初速方向、惯性滞后、加速下坠、撞停、滑行中的任何一项 | **PH-011**（新）、PH-004 |
| 从木柱旁掠过，没有撞停感 | 逐帧看：1.7s、2.3s 人物都贴柱侧飞过，接触帧无速度归零、无衣料压变形 | **PH-011**（新）、PH-002 |
| 面部平静，撞击瞬间没有形变 | t=0.25s 侧面像平静的定妆照：眼睑放松、无皱眉、无咬牙；t=0.9s 脸完全转开 | **ME-010**（新）、ME-004 |
| 表情也根本读不出来 | `face_scale=3%`，低于 ME-006 的 10% 下限 | **ME-006** |
| 5s 镜头 `micro_beats=0` | 表格里 `emotion_start/end` 写了"震惊/剧痛"，但没进提示词，模型无从执行 | **ME-009** |

**根因**：不是规则缺，是**规则没有走到提示词**。表格字段（`physics_note`、`emotion_start/end`）填得再对，模型只看得见 `prompt_zh`——而这一镜的 `prompt_zh` 里物理与表演两项**一个字都没有**，关键帧本身又已经画成半空中的静止姿态，模型只能自由发挥。

**处置**：

1. 新增 `rules/PH-011`（受击方受力链六段）与 `rules/ME-010`（受击情绪极性与撞击帧被动形变）。
2. `docs/06` 第 2 层给出**受击镜头尾缀模板**，直接复制进 `prompt_zh`。
3. 场记核对新增硬检查：受击类镜头（踢/踹/撞/砸/击飞/抛掷/摔）的 `prompt_zh` 必须命中 ≥2 个受力链要素，`emotion_start/end` 不得出现正向词——SH001 当场被拦下（错误的 27 → 28 条）。
4. SH001 维持 `status=regen`：下一版按尾缀模板重写提示词，并补一张**带受力点的关键帧**（脚或肩入画、身体已被带起、衣袍朝运动方向拖尾）。

## 四、自动化命中情况

能机器判的部分已经写进 `tools/check_consistency.py`，跑一次就报：

```
$ python3 tools/check_consistency.py          # 正式模式
[错误] [ME-009] EP01-SC01-SH002 时长 4s、face_scale=12% 但只有 1 个节拍，必然匀速漂移（ME-001），需拆到 ≥2 个
[错误] [ME-009] EP01-SC01-SH003 时长 4s、face_scale=35% 但只有 1 个节拍，必然匀速漂移（ME-001），需拆到 ≥2 个
[错误] [PH-011] EP01-SC01-SH001 受击镜头的 prompt_zh 没写受力链：受力点/惯性滞后/加速下坠/撞停/滑行/扬尘 只命中 0 项，要求 ≥2（尾缀模板见 docs/06 第 2 层）
[警告] [ME-006] EP01-SC01-SH001 face_scale=3% 面部不可读，确认该镜确实不需要微表情
[警告] [ME-006] EP01-SC01-SH004 face_scale=0% 面部不可读，确认该镜确实不需要微表情
```

**ME-001、ME-003、ME-004、ME-005 目前无法自动判**——它们需要逐帧面部跟踪，当前管线不具备。**ME-010 的情绪极性可以自动判**（词表硬判），但"撞击帧有没有被动形变"仍需人眼。其余只能靠人眼按 `docs/06` 的步骤抽查。

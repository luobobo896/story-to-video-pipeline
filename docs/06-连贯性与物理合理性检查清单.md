# 06 · 连贯性与物理合理性检查清单

面向 AI 视频生成创作者的排错手册。每一类都给四件事：**症状 → 预防（分镜）→ 预防（提示词）→ 检查帧 → 修复**。

> 标记说明：`[已约束]` = 流水线里已有字段或闸门强制；`[本次新增]` = 本轮补进 `shots.csv` 与校验器。

---

## 一、人物站位与姿态连续性

### 常见症状

- 相邻分镜里同一人物坐 / 站 / 跪 / 躺无解释突变
- 镜头切换后人物位置跳跃（上一镜在画面左，下一镜突然到右）
- 人物朝向、视线方向与前后镜头不一致（越轴）

### 预防：分镜阶段 `[本次新增]`

- 每镜必填起止姿态：`pose_start` / `pose_end`（坐 / 站 / 跪 / 躺 / 蹲 / 趴）
- 每镜必填画内位置：`position_start` / `position_end`，用**绝对描述**——"画面左侧 1/3、面向画面右"，禁止写"旁边""对面"
- 每镜必填朝向与视线：`facing`（正 / 侧 / 背 + 朝向角）、`eyeline`（在看谁或什么）
- **一镜只允许一次姿态转换**。跨镜改姿态必须在剧本里有对应动作（"她站起来"），否则不允许
- 同场戏所有机位放在**180 度轴线同一侧**；必须越轴时，插入一个中性镜头（正面 / 背影 / 道具特写）作为过渡

### 预防：提示词 `[已约束]`

- 显式写起止状态：`起始=坐在桌前双手放桌面；结束=保持坐姿身体前倾`
- 写朝向：`人物面向画面右侧，视线看向右前方`
- 一镜最多一个姿态变化 + 一个景别变化（与"每镜最多双轴运动"同源）
- **首尾帧夹逼**：把姿态起点画成首帧、终点画成尾帧，模型只会插值，不会乱跑

### 检查帧

- **每个切点前后各 0.5s**：上一镜最后一帧 vs 下一镜第一帧，姿态 / 位置 / 朝向能否直接接上
- 每镜尾帧是否落在预期姿态（AI 常在结尾漂走）

### 修复

| 症状 | 处理 |
|---|---|
| 姿态错 | 重生成该镜：补强首尾帧 + 写清 `pose_start/pose_end` |
| 位置跳跃 | 插入桥接镜头（手部 / 脚下 / 道具特写）掩盖，或重生成 |
| 越轴 | 重排镜头顺序，或补一个中性镜头 |

## 二、人物穿透与碰撞

### 常见症状

- 身体与桌椅、墙壁、门窗穿插
- 肢体之间或人物与道具之间出现不合物理空间的交叠
- 多人场景中角色之间非预期穿透

### 预防：分镜阶段 `[本次新增]`

- **多人场景禁止横向排开 + 大幅走动**，改用"静态机位 + 台词指代"
- 尽量**避免人物与道具的物理交互**（拿杯、举物、开门）——这是穿透最高发区。能用特写 / 暗示镜头绕开就绕开
- 明确写出允许的遮挡关系："桌沿挡住腿部，椅背在人物身后"
- 一镜内每个人的动作幅度都限定为**小幅度**

### 预防：提示词 `[本次新增]`

- 正面表述遮挡关系：`身体与椅子保持正确前后遮挡，椅背在身后，不穿透`
- 避免多人同时大动作：`所有人保持小幅动作`
- 强交互动作（拿起 / 举起 / 抛掷）要么不写，要么写全接触点与起止位置

### 检查帧

- 人与物的**接触帧**（手 / 臀 / 肩 / 背接触点）
- 多人同框帧
- 快速运动帧（穿透最常出现在动作中段）

### 修复

| 症状 | 处理 |
|---|---|
| 单帧穿帮 | `higgsfield generate workflow draw_to_video` 改那一帧重渲染 |
| 局部区域穿帮 | 裁剪 / 遮罩 / 局部替换 |
| 整镜穿透严重 | 重生成，并把交互动作降级为暗示性镜头 |

## 三、物体物理规律

### 常见症状

- 运动轨迹违背重力、惯性、摩擦力
- 拿起 / 放下 / 抛掷时受力表现不自然
- 液体、布料、烟雾等软体或流体运动失真

### 预防：分镜阶段 `[本次新增]`

- 一个镜头**只做一种物理现象**，不同时洒水 + 布料飘
- `physics_note` 写清受力与结束状态：`杯子被放下后静止在桌面，不弹跳不漂浮`
- 软体 / 流体必须写**结束状态**，不能只写开始
- 纯自然风光 / 抽象流体适合纯文本生成；**带交互的动作必须给足约束**（起始位置、结束位置、接触点）

### 预防：提示词 `[本次新增]`

- 加物理锚点：`glass settles on the table and stays still`、`fabric falls and settles`
- 写介质 + 环境 + 收束：`雨水落到地面溅开，随后水流向画面右下`
- 避免"弹起""漂浮""旋转不停"等无收束描述

### 检查帧

- **0.25 倍速慢放**看抛出 / 落下 / 碰撞段
- 动作结束后的 0.5s（失真最爱出现在"收尾"）
- 物体与支撑面的接触帧

### 修复

| 症状 | 处理 |
|---|---|
| 物理失真 | 重生成并**降低动作复杂度**（宁可少动） |
| 反复失真 | 换更强模型或缩短时长重跑该镜 |
| 无法修好 | 用 0.3–1s 快切掩盖失真段（观众看不清），或改成"动作发生在画外" |

## 四、场景与道具连续性

### 常见症状

- 切换后布局、光照、道具位置变化
- 道具消失、变形或数量不一致
- 背景元素与前景人物比例、透视关系错误

### 预防：分镜阶段 `[已约束 + 本次新增]`

- 场景一律建成 `EN-###` 资产，**每镜挂载同一张场景参考图** `[已约束]`
- 光照方向写进 `EN-###` 锚点（如"主光从画面左上方"），每镜重复声明 `[已约束]`
- 道具建成 `PR-###`，写清**数量与位置**（"两只杯子，桌面左上角"）`[已约束]`
- 新增 `props_in_frame`：本镜应出现的道具及数量，切镜后逐项比对 `[本次新增]`
- 同场戏**锁焦段**：背景元素的比例由景别与焦段决定，焦段乱跳会让背景比例突变 `[本次新增]`

### 预防：提示词 `[已约束]`

- 收尾加场景锁：`背景布局、陈设与光照方向与参考图一致`
- 道具锁：`桌面上始终只有两只杯子，位置不变`
- 出现新场景元素必须有剧本依据，不临时加

### 检查帧

- 切点前后比对四样东西：**墙面挂饰、门窗位置、桌面物品、光源方向**
- 数道具数量（最容易出错）
- 检查水平线位置是否突然变化（透视错误的信号）

### 修复

| 症状 | 处理 |
|---|---|
| 场景漂移 | 重生成，强化场景参考图挂载顺序 |
| 道具消失 / 变形 | 重生成；或后期合成补上 |
| 光照方向错 | 重生成，或全片统一调色时拉回 |
| 背景比例错 | 重生成并锁焦段；或裁切掉异常区域 |

## 五、规避与修复：四层工程化

### 第 1 层 · 分镜设计阶段的强制标注 `[本次新增]`

`shots.csv` 新增 8 列，把"防错"从靠感觉变成必填：

| 列 | 解决上面的 |
|---|---|
| `pose_start` / `pose_end` | 姿态突变（问题 1） |
| `position_start` / `position_end` | 位置跳跃（问题 1） |
| `facing` / `eyeline` | 朝向与视线不一致（问题 1） |
| `props_in_frame` | 道具数量 / 位置不一致（问题 4） |
| `physics_note` | 受力与物理收束（问题 3） |

配合已有的 `action_start` / `action_end` / `emotion_start` / `emotion_end` / `axis_note`，一个镜头卡就完整描述了"人在哪、什么姿态、朝哪儿、做什么动作、场景什么状态"。

### 第 2 层 · 提示词约束模板（可复制尾缀）

```text
起始姿态：{pose_start}；结束姿态：{pose_end}
人物位于{position_start}，面向{facing}，视线看向{eyeline}
本镜只发生一个动作：{动作}
身体与{道具/家具}保持正确遮挡关系，不穿透
{道具}数量与位置保持不变，不凭空出现或消失
{物体}运动结束后静止在{位置}，不弹跳、不漂浮
背景布局、陈设与光照方向与参考图一致
禁止：角色变形、肢体融合、道具消失、场景变化、字幕水印
```

> 多数模型不暴露 `negative_prompt`，所以主体用**正面表述**；Seedance 系列可接受末尾的"禁止：…"声明，可作为补充。

### 第 3 层 · 生成后重点检查的帧与切点

| 检查对象 | 为什么 |
|---|---|
| 每个切点前后各 0.5s | 跨镜连续性全部在这里暴露 |
| 每镜首尾帧 | 姿态漂移与物理收尾 |
| 人与物、物与物的接触帧 | 穿透高发 |
| 多人同框帧 | 互相穿透 + 站位错乱 |
| 镜头中段（2–3s 后） | AI 常在生成中段开始漂 |
| 0.25 倍速看物理段 | 重力 / 惯性 / 软体失真 |

### 第 4 层 · 修复策略决策树

```text
发现错误
│
├─ 只有单帧穿帮，其余都好
│    └─ draw_to_video 改那一帧重渲染
│
├─ 局部区域穿帮（手、道具、边缘）
│    └─ 裁剪 / 遮罩 / 局部替换（后期）
│
├─ 整镜姿态、位置、朝向错
│    └─ 重生成该镜：补强首尾帧 + 写清 pose/position/facing
│
├─ 跨镜不衔接（单镜都对，接不上）
│    └─ 插入桥接镜头（特写 / 空镜 / 道具），不要硬接
│
├─ 物理失真反复修不掉
│    └─ 降级动作（改成暗示 / 画外）+ 0.3–1s 快切掩盖
│
└─ 已经进入剪辑阶段才发现
     └─ 只重做受影响的那一段，用 reframe / 重剪替换，不要全片重跑
```

**始终优先"重生成该镜"而不是"后期硬救"。** 后期修补只适合单帧与局部，整镜级问题越救越脏。

## 六、微表情与物理的专项规则

微表情与物理的**通用规则**在 [`rules/`](../rules/README.md)（跨项目复用）；本项目的实测数据与阈值校准在 [07-本项目实测与规则校准.md](07-本项目实测与规则校准.md)。

一句话版：

- **微表情**：`duration_s ≥ 4` 的镜头必须 `micro_beats ≥ 2`；面部高度占画面 `< 10%` 时不做情绪要求；首尾帧必须同时锁姿态与表情。
- **物理**：本系统没有物理引擎，重力/质量/碰撞/空气阻力**一概不存在**，只能靠提示词的时序描述 + 分段生成来逼近。

## 七、这些问题分别在哪道闸门拦住

| 问题类 | 闸门 | 校验项 |
|---|---|---|
| 1 站位 / 姿态 / 朝向 | G3 分镜 + G4 生成后 | `qa_continuity` |
| 2 穿透与碰撞 | G4 生成后 | `qa_physics` |
| 3 物体物理规律 | G4 生成后 | `qa_physics` |
| 4 场景与道具连续性 | G2 资产 + G4 生成后 | `qa_scene` + `qa_props` |
| 4 背景比例 / 透视 | G4 生成后 | `qa_spec` |
| 5 修复策略 | G4 未通过时 | 按决策树处理后才允许 `status=done` |

`status=done` 的镜头必须**十项 QA 全 pass**，否则校验器报错、G4 不通过，禁止进入剪辑。

# 07 · 微表情与物理合理性规则

本文档的规则来自 EP01-SC01 四镜 Demo 的真机实测（2026-09-16），不是通用经验罗列。

---

## 第一部分 · 微表情僵硬规则

### 判定用的测量方法（先定义清楚，规则才可执行）

```bash
# 面部区域帧间差异：裁出面部区域，逐帧与基准帧做差分，取平均差异百分比
ffmpeg -v error -i <clip> -vf "fps=8,crop=<w>:<h>:<x>:<y>,scale=120:100" -frames:v 1 out.png
magick base.png cur.png -compose difference -composite -colorspace Gray -format "%[fx:mean*100]" info:
```

按 0.3–0.5s 间隔采样，得到一串差异值 `d1..dn`，然后算两个指标：

- **变异系数 CV** = 标准差 ÷ 均值
- **峰值比 R** = 最大值 ÷ 均值

> 注意：这个指标包含头部转动与镜头运动的贡献，只能判"变化有没有节拍"，不能单独判五官。要分离五官需要更细的关键点跟踪，当前管线不具备。

### 通用规则（适用于所有自然人物微表情）

#### R-ME-01 · 匀速漂移：变化有量无节拍

| 项 | 内容 |
|---|---|
| **问题现象** | 整段镜头里表情一直在变，但没有"起—停—再起"，像被匀速拉动 |
| **判定标准** | 采样差异序列 **CV < 0.20 且 R < 1.5** 判为匀速漂移。自然表演应有爆发区间，CV > 0.5、R > 3 |
| **修正要求** | 把该镜的表情拆成 ≥2 个节拍，并给出各节拍的**时间点**。每个节拍 = 快速起（0.1–0.3s）→ 保持（0.5–1.5s）→ 释放 |
| **适用范围** | 所有时长 ≥2s 且面部可辨的镜头 |

#### R-ME-02 · 五官同步位移：整张脸一起动

| 项 | 内容 |
|---|---|
| **问题现象** | 眉、眼、口、下颌像被同一个滑块控制，同起同落，没有先后 |
| **判定标准** | 表情变化帧中，若眉眼区与口鼻区的差异值**比值落在 0.8–1.25 之间**（即几乎同步同幅），判为僵硬。自然表演中两者时序差通常 ≥2 帧 |
| **修正要求** | 在提示词中**按区域分写时序**："先眼睑收紧，约 0.3 秒后嘴角才下沉"。禁止只写一个笼统情绪词 |
| **适用范围** | 中近景及更近的镜头（面部高度 ≥ 画面高度 15%） |

#### R-ME-03 · 缺过渡帧：从起点直接跳终点

| 项 | 内容 |
|---|---|
| **问题现象** | 首帧是平静、尾帧是震惊，中间像被硬切，没有渐变的中间态 |
| **判定标准** | 若首尾帧之间的差异值在**前 20% 时间内已完成 70% 以上**，判为缺过渡 |
| **修正要求** | 首尾帧夹逼时必须**同时画姿态和表情**；只画姿态不画表情，模型就只能猜表情，猜出来的一定是过渡缺失的 |
| **适用范围** | 所有使用 `--start-image` / `--end-image` 的镜头 |

#### R-ME-04 · 表情与动作脱节

| 项 | 内容 |
|---|---|
| **问题现象** | 身体在剧烈动作，脸上却是中性表情；或身体静止，脸上却在大幅表演 |
| **判定标准** | 身体位移幅度与面部差异值的**趋势方向不一致**（例如身体位移曲线上升而面部差异曲线平坦） |
| **修正要求** | 在 `shots.csv` 里让 `emotion_start/emotion_end` 与 `action_start/action_end` **成对填写且语义一致**（"被踹中"对应"剧痛"，不是"平静"） |
| **适用范围** | 所有含动作的镜头 |

#### R-ME-05 · 表情模板复用：不同镜头同一张脸

| 项 | 内容 |
|---|---|
| **问题现象** | 第 3 镜和第 12 镜的"震惊"是一模一样的脸，只是角度不同 |
| **判定标准** | 跨镜头取面部归一化后比对，若差异值 **< 5%** 判为模板复用 |
| **修正要求** | 同一种情绪在同一集内出现 ≥2 次时，第二次必须换**触发方式**（第一次是视觉触发，第二次改成听觉触发）或换**强度档位** |
| **适用范围** | 同一集内情绪类型重复的镜头 |

#### R-ME-06 · 面部尺寸不足却要求表演

| 项 | 内容 |
|---|---|
| **问题现象** | 全景/远景里要求"眼神从涣散转笃定"，成片里根本看不出来 |
| **判定标准** | 面部高度 **< 画面高度的 10%** 时，任何微表情都不可读，直接判不合格 |
| **修正要求** | 微表情镜头一律用中近景以内（Z ≤ 4）；需要全景表现情绪时，改用**身体语言 + 景别切换**，不靠脸 |
| **适用范围** | 所有标注了情绪起止的镜头 |

#### R-ME-07 · 视线与情绪不同步

| 项 | 内容 |
|---|---|
| **问题现象** | 情绪已经转向，但视线还停在原处；或不看任何东西，眼神"空" |
| **判定标准** | `eyeline` 字段为空或写成"无""前方"这类无指向描述时，判为不可控 |
| **修正要求** | `eyeline` 必须写成可执行的目标："看向画面右侧的江景承"、"看向地上的人"、"低头看向地面" |
| **适用范围** | 所有面部可辨的镜头 |

### 特定规则（EP01 已暴露，本任务专用）

#### R-ME-T01 · 本片已确认的第一处僵硬（实测数据）

| 项 | 内容 |
|---|---|
| **问题现象** | SH003（撑地抬头，4.096s）整段表情只有一个"瞪眼微张口"的模板，只有头部角度在变 |
| **判定标准** | 实测采样差异序列 = 8.95 / 11.54 / 11.56 / 9.02 / 8.75（每 0.7s 一个间隔）→ **CV = 0.13**，**R = 1.16**，两项都低于 R-ME-01 的阈值 |
| **修正要求** | SH003 重做时给出两个节拍：**0–1.2s 从昏迷到苏醒（眼睑缓慢睁开、头抬起）** → **1.2–4.0s 聚焦到"买状元"这件事（瞳孔收紧、眉心下压、呼吸变浅）**。首帧要画"闭眼/半闭眼"，不能画成瞪眼 |
| **适用范围** | SH003，以及后续所有"苏醒/回神/打量"类镜头 |

#### R-ME-T02 · 本片情绪节拍数上限

| 项 | 内容 |
|---|---|
| **问题现象** | 想在一个镜头里同时演"震惊→难以置信→恐惧→强装镇定"，结果全被抹平 |
| **判定标准** | 单镜情绪节拍数 > 3 判为超载。有实测佐证：同一颗震惊戏，单镜 7 秒塞 9 个节拍 → 情绪峰值 PSNR 37–42 dB（≈冻结帧）；拆成三颗 2–3 秒各一主节拍 → 22–23 dB（表情到位） |
| **修正要求** | 单镜情绪节拍**甜区 1–2 个，硬上限 3 个**。超了就拆镜头，拆镜头本身就是表演 |
| **适用范围** | 本片全部 28 镜 |

#### R-ME-T03 · 单镜时长与微表情可读性的冲突

| 项 | 内容 |
|---|---|
| **问题现象** | 本片单镜定在 3–6s，但 4 秒里只放一个节拍就必然匀速漂移（R-ME-01 命中） |
| **判定标准** | `duration_s ≥ 4` 且 `micro_beats < 2` 时判为高风险 |
| **修正要求** | 在 `shots.csv` 增加两列：**`micro_beats`（本镜微表情节拍数，整数）** 与 **`face_scale`（面部高度占画面高度的百分比）**。规则：`duration_s ≥ 4` 时 `micro_beats ≥ 2`；`micro_beats > 0` 时 `face_scale ≥ 10` |
| **适用范围** | 本片全部镜头，后续所有集通用 |

#### R-ME-T04 · 首尾帧只画姿态不画表情（本片已犯）

| 项 | 内容 |
|---|---|
| **问题现象** | SH001–SH004 的关键帧全部只约束了姿态与构图，没有约束表情，导致视频里的表情由模型自由发挥 |
| **判定标准** | 关键帧生成提示词中若不含表情描述词，判为不合格 |
| **修正要求** | 关键帧提示词必须包含**情绪词 + 至少一个具体面部动作**（如"眉心微蹙、下唇略收"）。见 [06-连贯性与物理合理性检查清单.md](06-连贯性与物理合理性检查清单.md) 的提示词模板 |
| **适用范围** | 本片全部镜头的关键帧 |

## 第二部分 · 掉落行为的物理

### 先纠正前提：本系统里没有物理模拟这一层

**不存在重力加速度、质量、碰撞体、空气阻力这些配置项。** 本片用的是生成式视频模型（`seedance_2_0_mini` 等），它是从训练数据里学到运动统计先验的神经网络，内部没有刚体求解器、没有时间步长、没有接触约束。`higgsfield model get seedance_2_0_mini` 能列出的全部参数只有：

```
aspect_ratio, duration, resolution, generate_audio, image_references,
start_image, end_image, video_references, audio_references, genre, bitrate_mode
```

**没有一个与物理有关。**

所以"重力加速度是否设为 9.8"这个问题在本系统里无法成立——没有这个旋钮可拧。真正在控制掉落的是四件事：

| 实际控制项 | 作用 |
|---|---|
| 提示词文本 | 描述动作与受力，模型按其先验理解 |
| 首帧图（`--start-image`） | 锁定起始姿态与高度 |
| 时长（`--duration`） | 决定动作能摊开多少秒 |
| 模型自身的运动先验 | 决定"像不像"——**这一项不可配置，只能选模型档位** |

### 逐项对照：你列的五个约束，实际情况是什么

| # | 你问的约束 | 本系统实况 | 测到的问题 |
|---|---|---|---|
| 1 | **重力加速度（9.8 m/s²）** | **无此参数**。提示词里写了"受重力下坠"，但那只是文本，模型不解析物理量 | 无法设置，也无法保证 |
| 2 | **下落速度随时间递增** | **无求解器**，速度曲线完全由模型先验生成 | **实测不符合**：见下方轨迹测量 |
| 3 | **碰撞检测与地面阻挡** | **完全没有**。模型不知道"木柱"是障碍物，也不知道地面在哪 | **实测确实没发生碰撞**：SH001 的 `qa_physics=fail`——设计里要撞柱，成片里人直接落地，从未接触柱子 |
| 4 | **空气阻力 / 终端速度** | **无**。人体在几米量级的低速下落中，空气阻力本来也可忽略（终端速度约 50–60 m/s），这一项即使做了物理引擎也不是瓶颈 | 不构成实际问题 |
| 5 | **角色质量与受力** | **无**。没有质量概念，也没有冲量传递 | 表现为：落地无二次响应（无反弹、无碎屑、无冲击变形），衣袍在空中已经"提前铺开" |

### 实测：SH001 的垂直运动轨迹

方法：对 5.088 秒的片段按 12fps 抽帧，用帧间差分提取运动区域的垂直质心（行号，数值越大越靠下）。**注意：该测量含镜头后拉分量，只能作粗判，不是精确轨迹。**

```
时间     运动质心行号     区间位移
0.0s        69.7            —
1.0s        69.3          +0.0
1.75s       83.5         +14.2  ← 最快段
2.75s       90.0          +6.5
3.5s        92.9          +2.9  ← 几乎停滞
5.0s       113.4         +20.5  ← 后段是滑行/镜头后拉
```

**结论：垂直位移速率没有随时间单调递增。** 1.75–3.5 秒这一段位移几乎停滞（+9.4 行 / 1.75s），而自由落体在该区间应当是**加速**的。整段运动更像"被匀速搬运 + 后段滑行"，而不是"受重力加速下落"。

再叠加另一个实测事实：**全程没有与木柱发生任何接触**（关键帧里柱子就在画面左侧，成片里人落在柱子前方地面）。这些都不是"参数没调好"，而是**这一层根本不存在**。

### 一个必须先明确的设定冲突

剧本写的是"一脚踹出十米远"。按真实物理：从约 1.2m 高度落地需要 0.49 秒，要飞 10 米需要水平初速 **约 20 m/s（72 km/h）**——这不是人能踢出来的，是**武侠设定**。

但风格锚 ST-001 定的是"古装**写实**电影质感"。**这两件事是冲突的。** 现在必须先选一个：

- **方案 A · 风格化物理**（推荐）：保留夸张距离，但让**加速曲线符合直觉**——起段快、末段缓、有明确撞击和二次响应（尘土爆开、衣料停滞、轻微反弹）。观众不会拿尺子量，但会下意识觉得"假"。
- **方案 B · 写实物理**：把距离压到 3–4 米，更像真实的"被踹倒"。失去爽感，但质感统一。

### 可执行的修正路径（按成本从低到高）

**路径 1 · 提示词层（唯一现在就能用的）**

把物理写成**可检验的时序描述**，而不是形容词：

```
0.0-0.3秒：身体离地约1.2米，水平横飞，四肢因惯性向后甩开
0.3-0.8秒：加速下坠，衣袍被气流压向身后，不得提前铺开
0.8秒：后背撞上画面左侧木柱，撞击瞬间尘土从接触点爆开
0.8-1.2秒：身体沿柱子下滑受阻，随后沿青石地面滑出约1米后静止
全程不得出现慢动作，不得悬停，身体不得与木柱或地面穿插
```

关键是把**时间点、高度、接触对象、二次响应**四件事写死——这正是模型能理解的"物理"。

**路径 2 · 分段生成（成本最低、效果最稳）**

把"腾空 → 下坠 → 撞击"拆成三个 1–1.5 秒的短镜，每段只做一件事。这符合本片已有的"一镜一主节拍"规则，也能显著提高物理可信度。代价是镜头数增加，多花积分。

**路径 3 · 真物理引擎补参考（唯一能做到严格正确）**

如果确实要 9.8 m/s² 这种严格正确，唯一路径是：在 Blender 或物理引擎里用简单几何体算出轨迹 → 导出为参考视频 → 用 `--video-references` 让模型复刻运动。此时才有真正可设的参数：

| 参数 | 建议值 | 说明 |
|---|---|---|
| 重力加速度 | `g = -9.81 m/s²`（Y 轴） | 室内无风，无特殊重力设定 |
| 角色质量 | 60 kg（江小白偏瘦） | 用于碰撞冲量；比 70kg 标准值低 |
| 水平初速 | 方案 A：5–7 m/s；方案 B：2.5–3 m/s | 方案 A 保留武侠感，方案 B 写实 |
| 垂直初速 | 1.5–2.5 m/s | 被踹时身体上扬分量 |
| 空气阻力 | 可忽略（Cd ≈ 1.0–1.2，迎风面积 0.6–0.7 m²） | 终端速度 50–60 m/s，几米内无影响 |
| 木柱碰撞 | 圆柱直径 0.4 m，恢复系数 `e = 0.1` | 人体撞硬木几乎不反弹 |
| 地面摩擦 | 青石 `μ = 0.5–0.7` | 落地后滑动减速度 `a = μg ≈ 4.9–6.9 m/s²` |
| 帧率 | 24fps（单帧 41.7ms） | 与现有素材一致；撞击帧建议补到 60fps 再降速 |

**路径 4 · 后期变速（成本最低，但有上限）**

用 `ffmpeg -vf "setpts=..."` 给下落段做加速曲线。能改"速度感"，但改不了"没撞上柱子"这种**缺失事件**——那只能重生成。

### 本片的判断

**采用方案 A（风格化物理）+ 路径 1 + 路径 2。** 理由：本片是 120 集的爽剧，物理真实不是卖点，"看起来对"才是。而路径 3 需要引入 Blender 与额外的参考视频生成，收益与 120 集的产能不匹配。

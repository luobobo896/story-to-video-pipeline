## 三、案例记录

### 案例 1 · SH003：匀速漂移（命中 ME-001 / ME-009）

| 项 | 内容 |
|---|---|
| 镜头 | `EP01-SC01-SH003` 撑地抬头，4.096s，face_scale 35% |
| 测量 | 按 0.7s 间隔采样面部区域差异：**8.95 / 11.54 / 11.56 / 9.02 / 8.75** |
| 指标 | **CV = 0.13，R = 1.16**（自然表演应有 CV > 0.5、R > 3） |
| 现象 | 整段只有一个"瞪眼微张口"模板，只有头部角度在变 |
| 根因 | 单镜 4 秒只放了 1 个情绪节拍（`micro_beats=1`），模型没有节拍可演，只能把"抬头"这个动作摊匀到整段 |
| 处置 | `status=regen`。重做规格：0–1.2s 昏迷转苏醒（眼睑缓慢睁开、头抬起）→ 1.2–4.0s 聚焦"买状元"这件事（瞳孔收紧、眉心下压、呼吸变浅）。**首帧必须画半闭眼，不能画成瞪眼** |

### 案例 2 · SH001：掉落轨迹不符合重力（命中 PH-004）

| 项 | 内容 |
|---|---|
| 镜头 | `EP01-SC01-SH001` 被踹飞，5.088s |
| 测量 | 12fps 抽帧，帧间差分取运动质心行号 |
| 数据 | 0.0s→69.7；1.0s→69.3；**1.75s→83.5（最快段 +14.2）**；2.75s→90.0（+6.5）；**3.5s→92.9（+2.9，几乎停滞）**；5.0s→113.4（滑行/镜头后拉） |
| 结论 | 垂直位移速率**没有随时间递增**。1.75–3.5s 段几乎停滞，而自由落体在该区间应加速 |
| 附加事实 | 全程**未与木柱接触**（`qa_physics=fail`）——关键帧里柱子就在画面左侧，成片里人落在柱子前方地面 |
| 根因 | 生成模型无物理求解器，"撞柱"这个事件无法被保证；提示词只写了结果（"撞柱即停"），没写时序（何时、接触点、撞击后反应） |
| 处置 | `status=regen`，改用 `rules/PH-004` 的时序化写法 |

> 测量局限：质心含镜头后拉分量，只能作粗判，不是精确轨迹。

### 案例 3 · SH004：道具形态漂移（命中视觉十项的 `qa_props`）

| 项 | 内容 |
|---|---|
| 镜头 | `EP01-SC01-SH004` 刀芒特写，4.096s |
| 现象 | 参考图 PR-001 是长直刃带两处豁口；成片中刀身变成短宽刃、护手形制改变 |
| 附加现象 | 关键帧的"半透明冷白光刃 + 光尘"在视频里衰减成刀沿一道细光 |
| 根因 | ① 道具保持是当前档位模型的能力短板；② 首帧只给了一张图，没有尾帧夹逼，模型可自由演绎 |
| 处置 | `status=regen`，重做时补尾帧、并在提示词里锁定刀形三要素（直刃 / 三尺三寸 / 两处豁口） |

## 四、自动化命中情况

能机器判的部分已经写进 `tools/check_consistency.py`，跑一次就报：

```
$ python3 tools/check_consistency.py          # 正式模式
[错误] [ME-009] EP01-SC01-SH002 时长 4s、face_scale=12% 但只有 1 个节拍，必然匀速漂移（ME-001），需拆到 ≥2 个
[错误] [ME-009] EP01-SC01-SH003 时长 4s、face_scale=35% 但只有 1 个节拍，必然匀速漂移（ME-001），需拆到 ≥2 个
[警告] [ME-006] EP01-SC01-SH001 face_scale=3% 面部不可读，确认该镜确实不需要微表情
[警告] [ME-006] EP01-SC01-SH004 face_scale=0% 面部不可读，确认该镜确实不需要微表情
```

**ME-001、ME-003、ME-004、ME-005 目前无法自动判**——它们需要逐帧面部跟踪，当前管线不具备。这几条只能靠人眼按 `docs/06` 的步骤抽查。

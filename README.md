# 剧本 → 成片 一条龙流水线

> 当前阶段：`S0 未启动`　｜　画幅：`16:9`　｜　分发：抖音　｜　语言：纯中文　｜　最后更新：见 git 记录

## 一、这个方案解决什么

输入一份剧本 txt，输出一整部可以直接发布的短剧成片，并且保证**人物、物体、建筑、场景、风格这五类信息在"结构化 → 分集 → 分镜 → 生视频 → 剪辑 → 配音"的每一步都不跑偏**。

跑偏的根因只有一个：**状态存在对话里，不存在文件里**。所以本方案的第一原则是：

> **文件是唯一真相源（Single Source of Truth）。任何阶段、任何一次重开对话，都只从磁盘上的 `schema/` 读取状态，不从上下文记忆里读取。**

第二个原则是**资产必须先于镜头存在**。角色定妆图、场景参考图、风格锚图没有锁定之前，不允许进入分镜生视频阶段。

## 二、本项目已确定的参数

| 项 | 值 | 来源 |
|---|---|---|
| 画幅 | `16:9` 横屏母版 | 你指定 |
| 交付平台 | 抖音 | 你指定 |
| 语言 | 纯中文 | 你指定 |
| 人物身份锁定 | **定妆图三视图**（Soul 训练需 Basic 以上套餐，当前未购买） | 你的套餐状态 |
| 项目名 | 由剧本文件名推导 | S1 自动 |
| 集数 | 由剧本结构分析得出 | S1 自动 |
| 单集时长 | 从剧本的时间标注与场次密度推导 | S1 自动 |

### 关于 16:9 上抖音（重要，请先看）

抖音的主流形态是 **9:16 竖屏全屏**。16:9 横屏在信息流里会被上下留黑边或缩成小窗，通常完播率更差。

本方案的处理方式：**16:9 作为制作母版，9:16 作为分发版**。

| 版本 | 用途 | 怎么来 |
|---|---|---|
| 16:9 母版 | 保底、复用、二次剪辑、其他平台 | S6 直接产出 |
| 9:16 分发版 | 抖音主发 | `higgsfield generate workflow reframe` 转换，或剪辑时按安全区裁切 |

代价：横转竖会裁掉两侧画面，所以 **S3 分镜阶段就要按"中心安全区"构图**：主体、关键道具、字幕都放在画面中央的 9:16 区域内（横向保留中间约 56% 宽度），两侧只放可牺牲的环境信息。规则见 [docs/02-一致性控制.md](docs/02-一致性控制.md)。

如果你其实想直接做 9:16，说一声即可，改一个字段的事。

## 四、快速开始

```bash
# 1. 把剧本 txt 放进 project/raw/（文件名即项目名）
cp {{剧本文件名}}.txt project/raw/

# 2. 装 CLI（本机当前未安装）
curl -fsSL https://raw.githubusercontent.com/higgsfield-ai/cli/main/install.sh | sh
higgsfield auth login
higgsfield account status        # 确认可用额度（Soul 训练需 Basic 以上，本项目不走这条路）
higgsfield model list            # 核实现行模型，别照抄文档

# 3. 让 Codex 跑 S1：读剧本 → 推导项目名/集数/单集时长 → 写 schema/story_bible.json

# 4. 每完成一个阶段就跑一次校验
python3 tools/check_consistency.py
python3 tools/check_consistency.py --draft      # 分镜先出稿、资产后补时用
python3 tools/check_consistency.py --selftest   # 验证校验器本身没坏
```

## 五、阶段总览

| 阶段 | 名称 | 核心产出 | 落盘位置 |
|---|---|---|---|
| S0 | 项目初始化 | 目录、剧本指纹、项目元信息 | 全项目 |
| S1 | 剧本解析与结构化 | `story_bible.json` | `schema/` |
| S2 | 设定一致性确认 | 定妆图、场景图、风格锚图、`assets.json` | `project/work/assets/` |
| S3 | 分集与分镜 | `episodes.csv`、`shots.csv` | `schema/` |
| S4 | 视频生成 | 每镜 MP4 与 `job_id` | `project/work/clips/` |
| S5 | 配音与音频 | 每句台词音轨与旁白 | `project/work/audio/` |
| S6 | 剪辑与成片 | 16:9 母版 + 9:16 分发版 + 字幕 | `project/work/edit/` |
| S7 | 交付与归档 | 成片、封面、资产清单、归档包 | `project/delivery/` |

阶段的**闸门**（Gate）：每个阶段结束必须跑校验器并通过，才允许进入下一阶段。定义见 [docs/04-风险与校验点.md](docs/04-风险与校验点.md)。

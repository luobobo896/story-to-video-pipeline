# VD · 配音与字幕规则

管一件事：**台词、音色、字幕三者必须对得上，而不是各写各的。**

---

## VD-001 · 一个角色只绑一个音色 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 同一角色在不同镜头里声音变了 |
| **判定标准** | `assets.json.voices` 里同一 `character_id` 出现 ≥2 个 `VC-###` |
| **修正要求** | 音色是**资产**，走 `VC-###` 编号，在分镜里用 `voice_id` 引用。换音色的唯一动作是改 `assets.json` 那一行的 `voice_id`，不改分镜 |
| **适用范围** | 全集 |
| **依据** | 校验器 R11 强制唯一。实测：注册前 28 条 `VC-` 引用全部报错，注册后 0 条 |

## VD-002 · 台词时长预算：4.4 字/秒 + 留白 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 台词念完镜头还没完，或者镜头完了台词还在说 |
| **判定标准** | `audio_duration_s > duration_s` 即判超长（校验器 R8）。**预算公式：镜头时长 ≥ 台词字数 ÷ 4.4 + 0.5s 动作留白** |
| **修正要求** | 写分镜时按公式先算一遍。超了就三选一：① 拆镜头（把长台词分给两镜）② 精简台词 ③ 延长镜头。**不要靠提速（atempo）硬塞**——超过 1.15× 就开始失真 |
| **适用范围** | 所有带台词的镜头 |
| **依据** | 本机实测 16 句（`seed_speech`，中文）：22 字→4.85s、42 字→9.07s、46 字→10.44s、7 字→1.63s，折算 **4.4–4.6 字/秒**。低于 10 字的短句会有静音填充，折算率会偏低（5 字→2.66s） |

## VD-003 · 字幕时间轴跟真实音频，不跟理论时长 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 字幕出现得比声音早或晚，越到后面越偏 |
| **判定标准** | SRT 的时间轴由 `shots.csv` 的 `duration_s` 推出来，而不是由 `audio_duration_s` |
| **修正要求** | 先从 `tts_batch.py` 生成音频并回填 `audio_duration_s`，再由 `make_srt.py` 生成 SRT（它优先读 `audio_duration_s`）。**语音长于镜头时字幕截到镜头末并报警，不允许越到下一镜** |
| **适用范围** | 所有字幕 |
| **依据** | 分镜表的时长是设计值，配音的实际时长才是播出值；两者在本项目实测中差了最多 4.44s |

## VD-004 · 字幕单行字数上限 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 一条字幕挤成长句，手机上看不清或被平台 UI 遮住 |
| **判定标准** | 单行 > 20 字（中文）未折行 |
| **修正要求** | `make_srt.py --max-chars 20` 默认在标点处折成两行（`\N`）。**宁可折行也不缩字号**——缩字号在竖屏上会小于可读阈值 |
| **适用范围** | 所有字幕 |
| **依据** | 本片实测：46 字的台词折成两行后每行 23 字，在 1080×1920 下仍清晰；不折行则单行占满屏宽 |

## VD-005 · 音色必须试听定稿，不能凭名字选 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 按音色名字（英文名）选出来的人声与角色气质不符 |
| **判定标准** | 音色绑定没有经过"同一句台词多候选对比"的试听 |
| **修正要求** | 每个角色至少 2–3 个候选，**用同一句台词**生成，放到 `project/work/audio/audition/`，由作者听完再定稿。定稿前 `status` 保持 `draft` |
| **适用范围** | 每个新角色 |
| **依据** | `higgsfield voices list` 的 113 个预设音色**只有 id / name / status，没有语言、性别、年龄任何元数据**——名字（Arthur、Helena…）无法推断音色特征，只能试听 |

## VD-006 · 口型与配音的取舍 `[软]`

| 项 | 内容 |
|---|---|
| **问题现象** | 配音和嘴型对不上，或者为了对口型牺牲了声音质量 |
| **判定标准** | 对白镜头用了"先出无声画面 + 后配音"的路线 |
| **修正要求** | 工具链**没有独立的 lip-sync 模型**。两种路线二选一，**在 S3 分镜阶段就定**并写进 `model` 列：① 生成时带音频（`seedance_* --generate_audio true` / `kling3_0 --sound on` / `wan2_7`）——口型最好，但台词要写进提示词；② 先出无声镜头再配音——灵活，但口型对不上，只适合旁白/独白 |
| **适用范围** | 所有对白镜头 |
| **依据** | 当前 CLI 模型目录里没有任何 lip-sync 专用模型 |

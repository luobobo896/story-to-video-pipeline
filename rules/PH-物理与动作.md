# PH · 物理与动作规则

管一件事：**让观众相信那个东西真的有重量。**

> **前提**：生成式视频模型里**没有物理引擎**。重力、质量、碰撞、空气阻力一概不存在，能调的全部参数只有 `duration / resolution / aspect_ratio / start_image / end_image / image_references / prompt`。所以本规则不是"调参数"，而是**把物理写成模型能理解的时序描述**。

---

## PH-001 · 先判可移动性：这个东西能不能动？ `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 一脚把承重柱、墙壁、山石、"整体建筑"踢飞 |
| **判定标准** | 被击打物若属于**固定结构件**（承重柱、墙体、门槛、固定门框），判定为"不可移动"，**禁止写整体位移** |
| **修正要求** | 二选一：① 改为**局部破坏**（裂、断、崩角、掉屑）；② 把目标换成**可移动物**（香炉、灯架、兵器架、矮几、桌椅） |
| **适用范围** | 所有含击打、冲撞、抛掷的动作 |
| **依据** | 实测参考：直径 0.4m、高 4m 的硬木承重柱，体积约 0.5 m³、质量约 300–400 kg，加石制柱础约 450–550 kg；且上端顶着梁架、下端插在柱础里，属半刚性连接。**整根平移在物理上不成立** |

## PH-002 · 破坏点原则：接触必须先有"坏掉的地方" `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 脚一接触，物体整体飞出去，中间没有任何破坏过程 |
| **判定标准** | 描写中若缺少**破坏点 / 破坏方向 / 破坏程度**三项，判为不合格 |
| **修正要求** | 按顺序写：**接触点压溃 → 裂纹沿材质纹理延伸 → 局部断裂或连接失效 → 部件脱离**。示例：木柱被击打应先"木茬炸开、裂纹顺木纹上窜半尺"，而不是"整根飞出" |
| **适用范围** | 所有击打会产生破坏的动作 |
| **依据** | 重量感恰恰来自"某处承受不住"。没有破坏点就直接整体位移，是"轻飘飘"的根源 |

## PH-003 · 质量决定视觉速度 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 重物飞出时速度与轻物一样快，像纸板被吹走 |
| **判定标准** | 描写中若用"嗖地飞出""瞬间飞出"修饰质量 > 50 kg 的物体，判为不合格 |
| **修正要求** | **越重越"慢而沉"**。大质量物体写"缓缓离地""沉重地翻起"，不写高速修饰词 |
| **适用范围** | 所有被击飞 / 被抛掷的物体 |
| **依据** | 同样冲量下，离地速度与质量成反比。参考量级：人体踢击冲量约 20–200 N·s；让 350 kg 物体获得 2 m/s 需 700 N·s，接触 0.05s 则平均作用力约 1.4 吨力——**差 5–20 倍** |

## PH-004 · 加速曲线：下落必须越来越快 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 物体在空中匀速下坠或悬停，像在失重环境 |
| **判定标准** | 下落段的垂直位移速率**未随时间递增**，判为不合格 |
| **修正要求** | 抛物段 = **水平匀速 + 垂直加速**。必须写出"下坠越来越快"。可写具体时间点分段：「0.3–0.8 秒加速下坠，衣袍被气流压向身后」 |
| **适用范围** | 所有含腾空、下落、抛掷的镜头 |
| **依据** | 自由落体 `g = 9.81 m/s²`；从 1.2m 高度落地约需 0.49s。本机实测某镜头：垂直位移速率在 1.75–3.5s 段几乎停滞（+9.4 行 / 1.75s），与自由落体应有的加速相反 |

## PH-005 · 旋转来自偏心 `[软]`

| 项 | 内容 |
|---|---|
| **问题现象** | 物体翻转方向与击打点对不上，或无来由地自旋 |
| **判定标准** | 击打点、质心位置与旋转方向三者不自洽 |
| **修正要求** | 写清受力点相对质心的位置：**打在下部 → 上端向前倒**；**打在中段 → 整体翻滚**；**打在边缘 → 甩出并绕质心旋转** |
| **适用范围** | 所有被击飞并发生转动的物体 |
| **依据** | 旋转由力臂产生，力臂 = 击打点到质心的垂直距离 |

## PH-006 · 大质量落地不弹跳 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 几百公斤的物体落地后像皮球一样弹两下 |
| **判定标准** | 质量 > 50 kg 的物体落地后出现明显反弹，判为不合格 |
| **修正要求** | 写成"**砸实 + 碎裂 + 扬尘 + 不再移动**"。落地瞬间要有地面响应：砖面开裂、柱身嵌进砖缝、墙面剥落 |
| **适用范围** | 所有物体落地 |
| **依据** | 人体撞硬木的恢复系数约 `e = 0.1`，即反弹速度只有入射速度的 10%，肉眼几乎不可见 |

## PH-007 · 反作用力守恒：出招的人必须有代价 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 角色轻飘飘踢一下就把重物踢飞，自己纹丝不动 |
| **判定标准** | 击打重物的动作若缺少**支撑脚抓地 / 重心下沉 / 上半身反向补偿 / 收势后顿**四要素中的任意两项，判为不合格 |
| **修正要求** | 按发力链写全：**脚 → 小腿 → 大腿 → 腰胯 → 肩背**；起腿前腰胯先下沉，踢击瞬间重心随腿前移，对侧手臂后摆平衡角动量，踢完身体后顿并后撤半步卸力 |
| **适用范围** | 所有发力动作 |
| **依据** | 动量守恒与角动量守恒。**没有反作用力 = 没有施力 = 观众判定为假** |

## PH-008 · 环境必须响应 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 物体飞过空间却什么都没碰到、什么都没扬起，像在真空里 |
| **判定标准** | 描写中缺少**地面痕迹 / 碰撞对象 / 尘土碎屑 / 同类反应**中的任意两项 |
| **修正要求** | 至少补齐：① 离地时柱脚或物体底部刮起土痕；② 落地时地面开裂或凹陷；③ 撞到墙 / 家具时对方的反应（墙皮剥落、桌椅被带翻）；④ 尘土不是一团雾，而是**沿地面向外扩散的环**；⑤ 碎屑落地后有二次小位移（滚动、蹦跳）；⑥ 声音用"闷响 / 撕裂 / 呻吟"，不用爆炸式"轰"（除非确实是爆炸） |
| **适用范围** | 所有含大动作的镜头 |
| **依据** | 质量感的最后一环是环境反馈；缺了它，再准的轨迹也像贴图 |

## PH-009 · 链式反应必须完整 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 承重结构被破坏，上面的东西却安稳如初 |
| **判定标准** | 破坏承重件后若没有**上部结构失稳**的反应，判为不合格 |
| **修正要求** | 写出被破坏件的**支撑职责**及其后果：柱子断开 → 上方梁架失去支撑 → 屋顶局部塌陷 / 瓦片滑落 / 梁架发出呻吟。即便选择"只裂不断"，也要写"柱身微微倾斜、梁架吱呀一声、屋角灰尘簌簌落下" |
| **适用范围** | 所有涉及建筑结构的破坏 |
| **依据** | 承重件的破坏必然传导到它支撑的荷载上。**漏掉这一层，是建筑类破坏戏最大的不真实来源** |

## PH-010 · 风格化物理的边界：人可超常，物按写实 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 同一个镜头里，人一脚踹出十米远（超常），同时柱子被踢飞（也超常），结果观众只觉得假 |
| **判定标准** | 同一镜内若**人体与无生命物体的夸张系数差异超过一个数量级**，判为不合格 |
| **修正要求** | 采用**分级夸张**：**人可以有超常表现**（观众接受，因为角色设定就是高手/超能），**无生命物体按写实处理**（观众不接受物体"有超能力"）。若叙事必须让物体超常，必须在画面里建立"这不合常理"的信号：气浪环、柱础炸裂、梁架呻吟、天窗落灰、围观者本能后退——**缺这些信号，观众只会判定为特效做错** |
| **适用范围** | 所有含超常力量设定的项目 |
| **依据** | 观众的接受度取决于"这个东西有没有理由超常"。人有设定，物没有。**同样的夸张放在人身上成立，放在物上就崩** |

## 附 · 常用物理参考值

写动作描写时可直接查表，不必每次翻书。

| 参数 | 参考值 | 用途 |
|---|---|---|
| 重力加速度 | `g = 9.81 m/s²` | 抛物段加速；从 1.2m 落地约 0.49s |
| 人体踢击冲量 | 普通人 20–50 N·s；训练者 100–200 N·s | 判断"能不能踢动" |
| 硬木（榆木/楠木）密度 | 600–800 kg/m³ | 算木器质量 |
| 铜制器物 | 约 8,900 kg/m³ | 香炉、灯架 |
| 青石密度 | 约 2,600 kg/m³ | 柱础、地面 |
| 人体质量 | 成年男性 60–75 kg | 撞地、被抛掷 |
| 人体空气阻力 | 终端速度约 50–60 m/s | **几米级下落可忽略**，不必写 |
| 人体撞硬木恢复系数 | `e ≈ 0.1` | 落地几乎不反弹 |
| 木-木摩擦系数 | 静止 0.4–0.6 / 滑动 0.3–0.5 | 地面滑行减速 |
| 石-木摩擦系数 | 静止 0.5–0.7 | 同上；减速 `a = μg ≈ 4.9–6.9 m/s²` |
| 24fps 单帧间隔 | 41.7 ms | 撞击帧建议 60fps 拍再降速 |

**随时可用的快速判断链：**

```
这个东西能动吗？             → 不能 → 改局部破坏或换目标（PH-001）
能动的话它多重？             → 决定写"缓缓"还是"嗖地"（PH-003）
接触点先坏还是整体动？        → 必须先坏（PH-002）
它撑着什么？                 → 撑着别人就得写连锁（PH-009）
出招的人付了什么代价？        → 没代价就重写（PH-007）
环境怎么响应？               → 至少补两项（PH-008）
```

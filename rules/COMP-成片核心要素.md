# COMP · 成片核心要素清单

管一件事：**什么样的产物才算"一集短剧"，而不是一堆素材。**

清单分三类，判定方式不同：

| 类 | 含义 | 缺了的后果 |
|---|---|---|
| **A 类** | 缺了**根本不构成**一部剧 | 放不出来，或放出来不是剧 |
| **B 类** | 缺了**平台不认** | 能播，但被降权、被压、被用户划走 |
| **C 类** | 缺了**质量塌陷** | 能发，但观感"业余" |

三类都算核心要素，但**修的方式不同**：A 类必须先有，B 类必须过检，C 类按需补。

## A 类 · 缺了根本不成立

### COMP-A1 · 视频轨

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 没有画面就不是视频，这是唯一的物理必需项 |
| **判定标准** | 成片容器里存在一条视频流，且编码 / 分辨率 / 帧率合规 |
| **载体与命名** | `EP<NN>_16x9_v<###>.mp4`（母版）、`EP<NN>_9x16_v<###>.mp4`（分发版） |

### COMP-A2 · 声音轨

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 静音的不是短剧，是动图；平台也会把无音轨内容判为残缺 |
| **判定标准** | 成片里存在音频流，且**不是纯静音**（`silent: false`） |
| **常见误判** | **有音轨不等于有剧**。生成模型自带的原声（环境噪声）不等于台词配音，台词必须单独生成并混进去 |
| **载体与命名** | `project/work/audio/EP<NN>-SC<NN>-SH<NNN>_v<###>.mp3` |
| **依据** | 本项目实测：demo 成片有 `aac` 音轨，但那只是 seedance 生成的原声——16 条台词音频一条都没进成片 |

### COMP-A3 · 台词（对白或旁白）

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 短剧靠信息驱动，没有台词观众看不懂剧情；纯画面叙事是另一种体裁 |
| **判定标准** | 每个 `dialogue` 非空的镜头都有对应音频，且 `audio_duration_s ≤ duration_s` |
| **依据** | rules/VD-001 ~ VD-003 |

## B 类 · 缺了平台不认

### COMP-B1 · 字幕

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 竖屏短剧的观众**大部分在静音环境刷**；没有字幕等于对这批人不存在 |
| **判定标准** | 存在与成片同名的 `.srt`，**或**成片带语言标记的字幕轨 |
| **格式要求** | 单行 ≤ 20 字、超长折行不缩字号（VD-004）；时间轴跟真实音频（VD-003） |
| **载体与命名** | `project/work/edit/EP<NN>.srt` |
| **依据** | `ffmpeg-skill` 的 `check.py --platform tiktok` 把 `subtitles none` 列为 WARN |

### COMP-B2 · 分发画幅

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 抖音是 9:16 竖屏信息流；横屏会被加黑边或缩成小窗，直接损失完播率 |
| **判定标准** | 分发版为 9:16 且短边 ≥ 1080 |
| **载体与命名** | `EP<NN>_9x16_v<###>.mp4` |
| **依据** | rules/FF-009；本项目 SH001 就栽在这条上 |

### COMP-B3 · 响度合规

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 不达标平台会自己压，过程中把混音拽得忽大忽小，**你失去对声音的控制权** |
| **判定标准** | `check.py` 的 loudness PASS（抖音 −14 ± 2 LUFS），真峰值 ≤ −1 dBTP |
| **载体** | 无独立文件，是成片的属性 |
| **依据** | rules/FF-006 / FF-007 |

### COMP-B4 · 封面

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 封面决定点击率，是短剧的"第二块屏幕"，不是附属品 |
| **判定标准** | 交付目录含横版与竖版两张封面 |
| **载体与命名** | `project/delivery/cover_16x9.jpg`、`cover_9x16.jpg` |
| **依据** | docs/01 S7 |

## C 类 · 缺了质量塌陷

### COMP-C1 · 环境音与音效

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 只有台词没有环境音的成片叫"干"；脚步、衣料、撞击、雨声是真实感的载体 |
| **判定标准** | `project/work/audio/sfx/` 非空，且按镜头命名 |
| **载体与命名** | `project/work/audio/sfx/EP<NN>-SC<NN>-SH<NNN>_<类型>_v<###>.mp3` |
| **依据** | rules/PH-008 要求"环境必须响应"，音效是响应的一半 |

### COMP-C2 · 背景音乐

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | BGM 承担情绪引导；没有 BGM 的短剧，情绪全靠观众自己补 |
| **判定标准** | 成片里存在 BGM 轨（不必单独交付） |
| **注意** | 混音优先级 **台词 > 环境音 > BGM**；BGM 压过台词是最常见的错误 |
| **依据** | docs/01 S6 |

### COMP-C3 · 片头标题

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 观众需要在前 3 秒知道"这是什么剧"；剧名 + 集号是最低限度的自我说明 |
| **判定标准** | 成片前 3 秒内出现剧名或集号 |
| **依据** | 短剧的前 2 秒是生死线（`ffmpeg-skill` 的 check 也按此判 hook） |

### COMP-C4 · 片尾钩子与引导

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 短剧是连载；结尾不留钩子、不引导追更，等于放弃下一集的流量 |
| **判定标准** | 成片最后 5 秒有悬念定格或引导字幕（关注 / 评论 / 下一集） |
| **依据** | 本项目 EP01 的 `hook_out` 已定义为「哦吼，造反吗？」定格，但尚未做成片尾包装 |

### COMP-C5 · 交付清单与资产台账

| 项 | 内容 |
|---|---|
| **为什么缺一不可** | 120 集的项目没有台账，必然出现"这集用哪版定妆图""上一集音色是不是这个" |
| **判定标准** | 交付目录含 `asset_manifest.md` 与 `delivery_checklist.md` |
| **载体与命名** | `project/delivery/asset_manifest.md`（项目 / 系列 / 通用三档，见 docs/02） |
| **依据** | docs/01 S7 |

## 附 A · 一集的最小交付包

```text
project/delivery/
├── EP01_16x9_v001.mp4        母版（A1）
├── EP01_9x16_v001.mp4        分发版（A1 + B2）
├── EP01.srt                  字幕（B1）
├── cover_16x9.jpg            横版封面（B4）
├── cover_9x16.jpg            竖版封面（B4）
├── asset_manifest.md         资产台账（C5）
└── delivery_checklist.md     交付检查表（C5）

成片内部必须具备：
  视频轨（A1）+ 音轨非静音（A2）+ 台词混入（A3）
  + 响度合规（B3）+ 片头标题（C3）+ 片尾钩子（C4）+ BGM（C2）

制作目录必须具备：
  project/work/audio/*.mp3     台词（A3）
  project/work/audio/sfx/*     环境音与音效（C1）
```

## 附 B · 怎么用

```bash
python3 tools/check_consistency.py --delivery    # 按本清单审计交付完整性
```

审计只在**正式模式**下把缺失项报为错误；草稿模式降级为警告，不影响出草稿。

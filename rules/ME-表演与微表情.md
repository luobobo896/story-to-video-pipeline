# ME · 表演与微表情规则

管一件事：**让角色的脸看起来像个人在演，而不是像一张图在动。**

---

## 判定用的测量方法

规则要可执行，先定义测量：

```bash
# 1. 裁出面部区域，逐帧与基准帧做差分，取平均差异百分比
ffmpeg -v error -i <clip> -vf "fps=8,crop=<w>:<h>:<x>:<y>,scale=120:100" frames/g_%03d.png
magick base.png cur.png -compose difference -composite -colorspace Gray -format "%[fx:mean*100]" info:
```

按 0.3–0.5s 间隔采样，得到差异序列 `d1..dn`，算两个指标：

- **CV（变异系数）** = 标准差 ÷ 均值 —— 衡量"变化有没有节奏"
- **R（峰值比）** = 最大值 ÷ 均值 —— 衡量"有没有爆发点"

**测量局限（必须知道）**：该指标包含头部转动与镜头运动的贡献，只能判"变化有没有节拍"，**不能单独判五官**。要分离五官需要关键点跟踪，当前管线不具备。所以规则 ME-002 只能靠人眼复核，不能自动化。

---

## ME-001 · 匀速漂移：变化有量无节拍 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 整段镜头表情一直在变，但没有"起—停—再起"，像被匀速拉动 |
| **判定标准** | 采样差异序列 **CV < 0.20 且 R < 1.5** 判为匀速漂移。自然表演应有爆发区间：**CV > 0.5、R > 3** |
| **修正要求** | 拆成 ≥2 个节拍并给出**时间点**。每节拍 = 快速起（0.1–0.3s）→ 保持（0.5–1.5s）→ 释放 |
| **适用范围** | 所有时长 ≥2s 且面部可辨的镜头 |
| **依据** | 本机实测：某近景 4.096s 镜头采样差异 8.95 / 11.54 / 11.56 / 9.02 / 8.75 → CV = 0.13、R = 1.16，命中本规则。自然表演的 CV 通常 > 0.5（节拍之间有明显平缓段） |

## ME-002 · 五官同步位移：整张脸一起动 `[软]`

| 项 | 内容 |
|---|---|
| **问题现象** | 眉、眼、口、下颌像被同一个滑块控制，同起同落，没有先后 |
| **判定标准** | 表情变化帧中，眉眼区与口鼻区的差异值**比值落在 0.8–1.25** 判为同步。自然表演中两者时序差通常 ≥2 帧 |
| **修正要求** | 提示词**按区域分写时序**：「先眼睑收紧，约 0.3 秒后嘴角才下沉」。禁止只写一个笼统情绪词 |
| **适用范围** | 面部高度 ≥ 画面 15% 的镜头 |
| **依据** | 人脸的 AU（面部动作单元）天然不同步，眉眼动作通常先于口部；模型若整脸同步位移，说明它没在建模 AU 而是整体变形 |

## ME-003 · 缺过渡帧：从起点直接跳终点 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 首帧平静、尾帧震惊，中间像被硬切，没有渐变中间态 |
| **判定标准** | 首尾帧之间差异值的 **70% 在前 20% 时间内完成**，判为缺过渡 |
| **修正要求** | 首尾帧夹逼必须**同时画姿态和表情**；只画姿态，模型只能猜表情，猜出来的一定过渡缺失 |
| **适用范围** | 所有使用 `--start-image` / `--end-image` 的镜头 |
| **依据** | 本机实测：关键帧只约束了姿态与构图时，视频表情完全由模型自由发挥 |

## ME-004 · 表情与动作脱节 `[软]`

| 项 | 内容 |
|---|---|
| **问题现象** | 身体剧烈动作、脸却是中性；或身体静止、脸在大幅表演 |
| **判定标准** | 身体位移曲线与面部差异曲线**趋势方向不一致** |
| **修正要求** | `emotion_start/end` 与 `action_start/end` 必须成对填写且语义一致（"被踹中"配"剧痛"，不是"平静"） |
| **适用范围** | 所有含动作的镜头 |
| **依据** | 情绪与动作共享同一套身体状态；分裂即出戏 |

## ME-005 · 表情模板复用 `[软]`

| 项 | 内容 |
|---|---|
| **问题现象** | 不同镜头的"震惊"是同一张脸，只是角度不同 |
| **判定标准** | 跨镜头面部归一化比对，差异 **< 5%** 判为复用 |
| **修正要求** | 同一情绪在一集内出现 ≥2 次时，第二次必须换**触发方式**（视觉触发→听觉触发）或换**强度档位** |
| **适用范围** | 同集内情绪类型重复的镜头 |
| **依据** | 观众对重复的表情模式敏感度高于对重复的构图；模板复用是"AI 味"最直接的来源 |

## ME-006 · 面部尺寸下限 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 全景里要求"眼神从涣散转笃定"，成片里根本看不出来 |
| **判定标准** | 面部高度 **< 画面高度 10%** 时，任何微表情都不可读，判不合格 |
| **修正要求** | 微表情镜头一律用中近景以内（Z ≤ 4）；需要全景表现情绪时改用**身体语言 + 景别切换**，不靠脸 |
| **适用范围** | 所有标注了情绪起止的镜头 |
| **依据** | 面部占画面 10% 时，人眼在移动影像中可分辨的面部变化已接近感知阈值 |

## ME-007 · 视线必须可执行 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 情绪已转向，视线还停在原处；或不看任何东西，眼神"空" |
| **判定标准** | `eyeline` 字段为空，或写成"无""前方"这类无指向描述 |
| **修正要求** | 写成具体目标：「看向画面右侧的江景承」「低头看向地面」「看向厅堂中央」 |
| **适用范围** | 所有面部可辨的镜头 |
| **依据** | 视线是情绪的接收端；不写接收端，模型只能让眼睛乱飘 |

## ME-008 · 情绪节拍数上限 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 想在一个镜头里演完"震惊→难以置信→恐惧→强装镇定"，结果全被抹平 |
| **判定标准** | 单镜情绪节拍 **> 3 判为超载** |
| **修正要求** | 单镜甜区 **1–2 个**、硬上限 3 个。超了就拆镜头——**拆镜头本身就是表演** |
| **适用范围** | 全部镜头 |
| **依据** | 实测对照：单镜 7 秒塞 9 个节拍 → 情绪峰值 PSNR 37–42 dB（≈冻结帧，脸完全没动）；拆成三颗 2–3 秒各一主节拍 → 22–23 dB（表情到位）。**拆镜头贡献了绝大部分效果** |

## ME-009 · 时长与节拍必须匹配 `[硬]`

| 项 | 内容 |
|---|---|
| **问题现象** | 单镜 4–6 秒只放一个节拍，必然匀速漂移（ME-001 必命中） |
| **判定标准** | `duration_s ≥ 4` 且 `micro_beats < 2` 判为高风险；`micro_beats > 0` 时 `face_scale < 10` 判为不可读 |
| **修正要求** | 分镜表必须填 **`micro_beats`（微表情节拍数）** 与 **`face_scale`（面部占画面高度百分比）** 两列，并满足上述约束 |
| **适用范围** | 全部镜头 |
| **依据** | ME-001 的成因；本规则把"要不要拆"从感觉变成填表 |
